# 线索收件箱

这里存放尚未进入正式选题池的题材。每个线索建立一个 Markdown 文件，文件名使用简短英文 slug，例如 `the-company-name.md`。

## 线索卡模板

```markdown
---
title:
slug:
region:
period:
category:
status: 线索
created_at:
updated_at:
---

# 一句话故事

用一句话说明：谁想得到什么、用了什么离谱手段、最后发生了什么。

## 为什么值得讲

- 新颖点：
- 核心冲突：
- 可能的反转：
- 可解释的资本/制度机制：
- 与常见题材的区别：

## 初始来源

| 来源 | 链接 | 等级预估 | 它可能证明什么 |
|---|---|---|---|

## 风险初筛

- 是否涉及仍在世的个人：
- 是否涉及仍在经营的国内企业：
- 是否已有法院、监管或破产结论：
- 是否存在明显诽谤、隐私或版权风险：
- 暂不采用的原因：

## 影像可行性

- 可用直接影像：
- 可用情境替代：
- 版权与授权初步判断：

## 准入决定

- 结果：拒绝 / 搁置 / 进入研究
- 理由：
- 日期：
```

线索卡只用于判断是否值得投入，不应把未经核验的故事写成事实。
