## 母稿与口播门禁

- [ ] 已按 `skills/story-video-craft/SKILL.md` 确定唯一叙事分支并写明故事合同
- [ ] 因果台账逐行首尾相接，信息释放图未隐藏理解当前行动所必需的事实
- [ ] 架构稿已完成章节级`C###`事实绑定
- [ ] 口播稿与架构稿版本对应一致
- [ ] 冷开场提供一个冲突中心、一个离谱结果和一个留在观众心里的问题（由场景自带，旁白不口头抛问）
- [ ] 陌生实体与核心金额已有最小参照系
- [ ] 每章包含人物行动、局面变化和下一问
- [ ] 连续机制解释后立即回到人物选择或后果
- [ ] 背景、配角、专名和数字均有后续作用，或已移出旁白
- [ ] 关键铺垫在动作层回收，结尾赋予开场新的含义
- [ ] 只保留一个最终主题落点
- [ ] 未复制参考创作者的口头禅、固定角色、栏目话术、标题句法、惯用比喻或声音身份
- [ ] 已运行证据闭环与口播可读性审计
- [ ] 已完成一次实录朗读
- [ ] 镜头文档（`script/shots.md`）与口播稿逐段对齐，旁白省略的参照系均已由画面承接
- [ ] 观感评估（`skills/viewer-experience-review/SKILL.md`）通过，无阻塞项
