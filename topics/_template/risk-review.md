# 发布前风险复核

> 本清单用于编辑审查，不替代针对具体司法辖区的专业法律意见。

## 1. 主体与现实风险

- [ ] 主角所在国家/地区及适用语境已确认
- [ ] 涉及人物是否仍在世已确认
- [ ] 涉及机构是否仍在经营已确认
- [ ] 国内仍在经营企业没有被作为未经必要审查的负面主角
- [ ] 是否存在正在进行的诉讼、调查或尚未生效的裁决已说明
- [ ] 对未定案行为使用“被指控、监管称、法院认定”等准确归因

## 2. 事实与措辞

- [ ] 所有高风险陈述均绑定事实编号
- [ ] 指控、判决、上诉、和解、撤诉、无罪等法律状态没有混用
- [ ] 没有把公司的行为自动归到每名员工或股东
- [ ] 没有根据结果反推人物当时的主观动机
- [ ] 争议事实呈现了重要反方说法
- [ ] 标题、封面和短视频钩子没有超出正文证据

## 3. 隐私与伦理

- [ ] 删除与公共利益无关的住址、联系方式、证件、未成年人信息
- [ ] 对受害者、弱势群体和非公共人物采用克制表述
- [ ] 幽默没有以受害者遭遇为笑点
- [ ] 没有公开可能导致骚扰、模仿犯罪或现实伤害的非必要细节

## 4. 版权与素材

- [ ] 引语长度与用途合理，并标明来源
- [ ] 图片、视频、音乐、影视替代素材均登记来源和权利状态
- [ ] “网上能找到”没有被视为“可以自由使用”
- [ ] 对无法确认授权的素材准备了替代方案
- [ ] 仓库未上传无权公开分发的媒体文件

## 5. 最终结论

- 风险等级：低 / 中 / 高 / 暂停发布
- 尚未解决的问题：
- 必须修改的段落：
- 需要外部专业意见的问题：
- 审核人：
- 审核日期：
- 结论：通过 / 有条件通过 / 不通过
