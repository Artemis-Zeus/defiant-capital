# Theranos：被倒置的验证链

## 一句话故事承诺

一家必须接受严格医学验证的公司，如何让投资人、董事、药企、零售商和媒体把彼此的出现误当成“别人已经验过货”，最终把社会证明替代了技术证明。

## 核心机制

私募公司的信息不透明、保密制度与跨领域权威背书形成验证责任外包：每个参与者掌握的只是一部分信息，却把其他参与者的存在当作独立尽调结果。
