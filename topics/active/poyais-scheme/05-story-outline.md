# 故事结构

## 核心表达

- 一句话故事：一个人先把“国家”做成一整套文件和金融产品，再让现实去追赶纸面承诺；现实追不上时，投资损失变成了移民灾难。
- 核心问题：人们购买的究竟是土地、国债，还是一套看起来足够完整的信用叙事？
- 核心机制：声望背书 + 文件权威 + 主权债热潮 + 跨洋信息差 + 承诺升级。
- 情绪曲线：好笑的纸面建国 → 令人佩服的包装能力 → 不安 → 生存灾难 → 对制度与受害心理的余味。
- 最大反转：受害者不是只在伦敦损失钱，有人真的搬去了宣传中的国家。
- 最终余味：骗局最危险之处，可能不是谎言写得多大，而是周围真实元素足够多。

## 章节设计

### 0. 冷开场｜国家的第一批“公民”到了，国家却没到

- 场景：船、纸币、地图与登陆后的空白现实并置。
- 已证实事实：Hastie 的航程记录；宣传册与债券实物确实存在。[C003][C004][C005]
- 暂不使用：未经统一的死亡人数。

### 1. 人物与信用｜一个履历比国书更好用的将军

- MacGregor 的军人/冒险者身份如何成为信用抵押。
- 需要补证：哪些履历真实，哪些被营销放大。
- 对应主张：C001、C002。

### 2. 纸面建国｜先有说明书，再有国家

- 宣传册、地图、制度、头衔、纸币和债券形成相互印证的外观。
- 解释：“材料彼此指向”不等于独立验证。
- 对应主张：C003、C004。

### 3. 风险升级｜买资产的人，变成了移民

- 从债券/土地证书升级到家庭迁移。
- 航程与乘客数字保留来源口径。
- 对应主张：C005。

### 4. 关键反转｜纸面上的城市无法接船

- 抵达现实与宣传材料逐项对照。
- 不把真实海岸和虚构国家制度混为一谈。
- 对应主张：C001、C003、C006。

### 5. 失控与结局｜损失不再只是账面数字

- 疾病、救援、转移 Belize、返英；先做人数表再写稿。
- 后续法国/英国版本说明骗局为何没有在第一次曝光时终止。
- 对应主张：C007、C008。

### 6. 机制拆解｜“国家信用”如何被手工组装

- 真实履历为第一层；印刷物和机构名称为第二层；金融中介和市场热潮为第三层；受害者迁移承诺为第四层。
- 反例与边界：不能把所有海外殖民/新国家融资等同骗局，也不能用后见之明嘲讽信息条件有限的投资者。

### 7. 结尾

- 回扣“国家没到”的开场。
- 留给观众的问题：当资产只能通过它自己制造的文件被验证时，尽调究竟在验证什么？
