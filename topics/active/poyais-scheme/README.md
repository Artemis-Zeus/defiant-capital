# Poyais：被包装出来的国家信用

## 一句话故事承诺

Gregor MacGregor 把军功、土地权利主张、地图、宣传册、债券和纸币拼成一个可交易的“国家”；当移民真的抵达时，纸面国家与现实之间的距离变成了一场生存灾难。

## 可行故事线（已确认）

1. **人物与信用**：MacGregor 的战争经历为他提供第一层可信度。
2. **纸面建国**：Poyais 被包装成有政府、城市、银行、货币和发展前景的国家。
3. **资本化**：土地证书、债券与移民计划把叙事变成可购买资产。
4. **兑现时刻**：移民跨洋抵达，发现宣传中的基础设施并不存在。
5. **反转与余波**：骗局并未立刻带来清晰惩罚，且后来的简单“凭空造国”叙事可能忽略真实土地权利主张与当时政治背景。
6. **机制**：主权债热潮、名望背书、纸面文件的权威感、跨洋信息差和受害者的承诺升级。

## 题材状态

- 当前阶段：研究
- 事实成熟度：已交叉验证（主线）；存在争议（人数、土地权利性质、MacGregor 的主观计划）
- 最大证据缺口：债券发行条款、移民批次与死亡数字需要以原件和多份同期材料校准。
- 最大法律或伦理风险：不能把有争议的土地权利问题压缩成“连土地都不存在”；死亡人数必须保留口径。
- 下一步动作：逐页阅读 Clavel 论文、Hastie 叙事和 1822 年宣传册，完成移民名单与债券条款表。

## 当前结论

- 已确认：存在可讲的完整主线；同期宣传品、债券实物和移民第一人称记录均可获得。
- 尚不确定：不同来源对抵达人数、死亡人数和返英人数的口径不一致。
- 来源冲突：大众叙事常说“国家完全不存在”，学术研究强调其与真实土地权利、殖民政治及金融实验的复杂关系。
- 下一步：把“真实土地/虚构国家机构/夸大开发状况”拆成三个独立事实问题。
