# Poyais：被包装出来的国家信用

## 一句话故事承诺

Gregor MacGregor 把军功、一项真实的土地授予、地图、宣传册、债券和纸币拼成一个可交易的"国家"；当移民真的抵达时，纸面国家与现实之间的距离变成了一场生存灾难。

## 可行故事线（已确认）

1. **人物与信用**：MacGregor 的战争经历与 1820 年的真实土地授予为他提供第一层可信度。
2. **纸面建国**：Poyais 被包装成有政府、城市、银行、货币和发展前景的国家。
3. **资本化**：土地证书、£200,000 债券与移民计划把叙事变成可购买资产。
4. **兑现时刻**：移民跨洋抵达，发现宣传中的基础设施并不存在；蚊子国王当面撤销授予。
5. **反转与余波**：1824 年庭审的拆分式裁定（报道属实+欺诈指控未证+1 先令赔偿）、法国阶段的未获罪、委内瑞拉的荣誉退场——惩罚并未对称兑现。
6. **机制**：主权债热潮、名望背书、纸面文件的权威感、跨洋信息差、殖民部"知情但不阻止"的制度空白。
