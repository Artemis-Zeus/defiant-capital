# Herstatt Bank 1974：一家银行倒在两个时区之间

## 一句话故事承诺

一家中型德国银行在固定汇率时代结束后豪赌外汇；监管机构关停它时，部分交易对手已经付出德国马克，却因时区与支付系统不同步尚未收到美元，一家银行的亏损于是变成了全球金融基础设施的漏洞。

## 可行故事线（已确认）

1. **旧经验失效**：Bretton Woods 固定汇率体系瓦解，外汇业务从低波动服务变成可投机市场。
2. **豪赌升级**：Herstatt 的未平仓外汇头寸远超内部限额，方向判断反复失误。
3. **救援失败**：损失和资产负债缺口扩大，潜在救援者无法确认真实损失。
4. **关停反转**：监管机构关闭银行，但外汇交易的两条支付腿并不同时结算。
5. **跨时区冲击**：德国马克已经支付，美元腿尚未交付；其他银行开始延迟付款，清算链条受阻。
6. **制度遗产**：“Herstatt risk”成为术语，巴塞尔委员会在危机余波中成立，数十年后 CLS 以 payment-versus-payment 降低同类风险。

## 题材状态

- 当前阶段：研究

- 最大编辑风险：不能把“Herstatt risk”说成银行倒闭的原因；它是倒闭发生后暴露出的结算风险。

## 当前结论

- 已确认：外汇投机、头寸远超限额、1974-06-26 关停、跨时区结算损失、纽约支付链冲击、巴塞尔委员会与 CLS 的制度关联。
- 尚不确定：准确关停时刻在不同权威材料中表述不一；交易台个人责任不能只依赖后世媒体。
- 来源冲突：BIS 给出 15:30 CET；ECB/BoE 对“德国营业日中段/收市后、美国是否已开市”的文字并不完全一致。
