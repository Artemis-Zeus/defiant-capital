# McKesson & Robbins 1938：审计师看了所有纸，却没去看货

## 一句话故事承诺

有前科的 Philip Musica 换成 F. Donald Coster 的身份控制一家真实上市药企，用虚构仓库、存货和应收账款制造增长；审计师检查了成堆文件，却没有实地观察存货或向债务人独立确认，最终一场骗局改写了现代审计的基本动作。

## 可行故事线（已确认）

1. **身份重启**：有犯罪记录的人以新姓名、学历与商业身份进入主流资本市场。
2. **真公司包假部门**：真实经营、真实上市地位与虚构的 crude drug 资产混在一起。
3. **纸面证据循环**：采购单、销售单、仓单和管理层解释相互印证，但都来自同一控制网络。
4. **审计失灵**：审计师没有实地看货，也没有独立确认关键应收账款。
5. **曝光**：约 2,000 万美元虚构资产被揭开，Coster 的真实身份和旧案同时浮出。
6. **制度反转**：今天看似常识的盘点观察与函证，正是在这类失败后被明确写入程序。
