## 三张核心人物动画

1. **人物关系图：** Citron居中；Raabe负责对外叙事；监事会批准；公共机构交钱；Merrill提供产品与融资；Moorlach在外围提出警告。
2. **Merrill双脚图：** 左脚“1992—1993警告、建议降杠杆、提出回购”；右脚“继续销售、融资、1994承销”。[C025]
3. **选举回旋镖：** 1994警告 → Moorlach落选 / Citron胜选 → 12月Citron辞职、县破产 → 1995 Moorlach接任。[C009—C011][C024]

## 两张机制动画

1. **Citron的杠杆机器：** 76亿公共存款 → Citron用证券抵押借约130亿短钱 → 206亿总组合。[C001][C002][C004]
2. **角色关系反转：** 加息 → Citron借钱更贵 / 产品付息下降 / 抵押品跌价 → 交易对手追保与缩贷 → 公共机构仍需现金 → 破产。[C008]

## 版权与真实性边界

- 政府材料优先重新绘制事实性数据；人物照片和新闻画面逐项登记权利状态、链接与时间戳。
- 不用AI生成的真人肖像冒充Citron、Raabe或Moorlach的同期照片。
- 若照片权利不清，人物存在感通过姓名卡、文件、选举票、办公室门牌和动作动画建立。
- 所有替代画面明确标注“示意”，不伪装成1994年橙县现场。
