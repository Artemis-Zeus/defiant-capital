## 来源冲突与口径

| 项目 | 口径 | 处理 |
|---|---|---|
| 损失 | Moorlach竞选计算逾12亿、12月1日15亿账面、20.2亿初估、16.9亿修订、约17亿已实现 | 按人物、日期和口径分层，不把任何一个数字写成同时成立 |
| “衍生品损失” | GAO称约9.7亿归于结构性票据 | 其余与非衍生资产和借款有关，拒绝单因叙事 |
| 杠杆 | 2.7:1 / 270% | 解释为总资产/本金，不说“借了2.7倍本金” |
| Merrill责任 | 提供产品和融资、发出风险警告、继续承销、SEC处分同时存在 | 全部呈现，不能剪成“它明知必崩仍诱骗Citron” |
| 法律结果 | SEC指控、和解禁令、行政认定、刑事责任是不同程序 | 母稿V0.2只写已纳入S007/S009的监管程序 |
| 12亿美元量级 | 占76亿美元参与者存款约15.8%；约为21.85亿美元县预算的54.9% | 两个分母用途不同；前者说明资金池风险，后者只提供财政体感，不能写成“县预算直接亏掉55%” |
| 1994年加息 | 美联储六次加息，目标利率3%→5.5%；SEC材料另有“加息造成五重影响”的机制拆分 | “六次”是政策动作次数，“五重”是组合受冲击的类型，不能混为“五次加息” |
| 13号提案后的纳税行为 | 有权威资料证明税率和评估值受到限制，但无材料支持危机期间“大量选民干脆不交税” | 只写选民通过制度限制政府加税，不写大规模拒缴税款 |
| 80年代复苏原因 | 通胀回落、利率下降、减税、国防开支和信贷环境变化同时存在 | 使用“共同作用”“几股力量”，拒绝单项政策决定论 |
| Campeau的作用 | 是80年代高杠杆扩张及其反转的横向样本 | 不暗示其破产导致美国衰退或橙县财政困境 |
