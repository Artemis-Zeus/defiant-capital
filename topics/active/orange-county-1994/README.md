# 橙县破产：高收益财政明星的反向利率赌局

## 一句话故事承诺

一个管理学校、城市和公共机构闲置资金的县级资金池，靠短期借钱购买长期债券和反向浮息产品，把76亿美元本金放大成206亿美元组合；当利率方向反转，账面损失、追保和融资拒绝把“稳健理财”推成市政破产。

## 核心机制

短期融资、长期资产、负久期衍生品和公共机构的高收益激励叠加：收益看似稳定，实际把利率风险与流动性风险集中在一个必须随时满足公共支出的资金池中。
