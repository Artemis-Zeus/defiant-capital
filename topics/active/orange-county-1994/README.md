# 橙县破产：赢了选举的人，让落选者来收拾残局

## 一句话故事承诺

财税官Robert Citron靠高收益赢得信任，把76亿美元公共存款撑成206亿美元组合；会计师John Moorlach在竞选中警告风险却落败。六个月后Citron辞职、橙县破产，Moorlach回来接手残局。

## 人物骨架

- 绝对主角：Robert Citron，策略与关键选择的推动者。
- 核心副手：Matthew Raabe，协助管理并参与对外披露与评级沟通。
- 对照人物：John Moorlach，竞选警告者与破产后的接盘者。
- 复杂配角：Merrill Lynch团队，兼具供货、融资、警告与承销角色。
- 许可者：县监事会。
- 代价承受者：学校、城市、特区等公共机构。

## 核心机制

成功收益为Citron积累权威，也给每个配角提供短期好处；短期融资、长期资产、反向浮息和公共预算依赖由此叠加。加息只负责揭开价格变化，交易对手拒绝续作才把账面损失变成破产。
