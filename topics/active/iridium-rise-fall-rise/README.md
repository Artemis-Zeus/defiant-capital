# Iridium：同一组卫星，两个完全不同的资本故事

## 一句话故事承诺

旧 Iridium 把全球卫星网络造了出来，却在商业服务启动约九个月后进入 Chapter 11；新买家 Dan Colussy 牵头的投资者以 2500 万美元取得运营资产，在被重置的债务、成本和客户组合上重开业务。故事讲的不是技术死而复生，而是同一技术资产如何被两套资本结构和客户定义判出相反结果。

## 当前结论

- **研究阶段：** 史料收集 V1.0 完成，可进入架构稿评审；母稿仍未开始。
- **核心因果链：** 工程可用且限制已知 → 实际订户与收入远低于贷款契约门槛 → 债务加速风险和 Chapter 11 → 停服与离轨倒计时 → 破产资产低价转让 → 成本基础、分销模式和客户用途重写 → 政府与细分行业形成稳定收入 → 现公司获得拟议并购定价。
- **绝对主角：** Dan Colussy。其身份、目标、当时所知、替代方案、行动与后果六字段均已有材料；旧 Iridium 则作为前半段机构型主角处理。
- **已验证的反差：** 法院记录 Iridium 向 Motorola 的相关合同转移约 37 亿美元；FCC 记录 2000 年成交价为 2500 万美元（其中 650 万美元现金）。两者不是同一估值口径，不计算“回报倍数”。
- **旧经营缺口已补：** 1999-03-31 实际为 7,188 名卫星语音订户、10,294 名总订户、累计现金收入 19.5 万美元；贷款契约要求分别为 27,000、52,000 和 400 万美元。
- **主体边界：** 旧 Iridium LLC、2000 年成立并买入资产的 Iridium Holdings/Iridium Satellite、2009 年 SPAC 交易后的 Iridium Communications Inc. 不是同一权益主体。
- **当前交易状态（截至 2026-08-31）：** Rocket Lab 与 Iridium 已签署合并协议；S-4 已生效，Iridium 股东会定于 2026-09-24；HSR 等待期已届满，FCC 申请已提交，但股东表决与 FCC 等批准尚未完成。

## 仍有缺口

- **非阻断：** 未取得 2000 年破产资产购买协议和批准令的完整公开扫描；2500 万美元价格、资产范围和成交日期已由法院意见、FCC 文书、两家发行人 SEC 披露交叉覆盖。
- **非阻断：** 旧系统“总成本 50 亿美元”主要来自同期媒体和事后报道；正文优先使用法院可核的“向 Motorola 约 37 亿美元转移”，若使用 50 亿美元必须写“同期报道估计”。
- **非阻断：** Dan Colussy 对旧、新月度运营成本的细节来自其公开陈述；只能归因给本人，不写成审计结论。
- **时效缺口：** 2026 交易状态会变化，进入母稿、录音和发布前均须重查。

## 风险项

- 法院意见审理的是历史期间偿付能力与欺诈转让要件；法院没有裁定“某一个原因导致失败”，也未认定手机尺寸是重大失败原因。
- 不能把 2500 万美元破产资产价与约 80 亿美元拟议企业价值写成同一资产的 320 倍收益。
- 不能写“Rocket Lab 已收购 Iridium”；截至本次核验仍是待完成交易。
- 美国政府是重构的重要客户和专用网关所有者，但“政府单独救活公司”仍是过度归因。
