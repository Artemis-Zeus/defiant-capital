# Iridium：同一组卫星，两个完全不同的资本故事

## 一句话故事承诺

一个耗资数十亿美元、商业服务启动约九个月便破产的全球卫星电话系统，资产在破产中以2500万美元被新公司接手；它没有变成更好的大众手机，却在政府、海事、航空和物联网等细分场景中活下来，并在2026年获得约80亿美元企业价值的待完成收购协议。

## 核心机制

不可逆基础设施的失败不等于技术资产归零。破产可以抹去旧资本结构和历史成本，让同一网络在更低成本基础上重新寻找愿意为“全球可达、关键任务”付费的客户。

## 题材状态

- 当前阶段：研究完成，待故事线评审
- 事实成熟度：旧系统、破产收购、政府收入与2026交易均有法院/SEC/公司原始材料
- 最大缺口：旧Iridium破产前逐月用户数与现金消耗的统一一手表格
- 最大风险：旧Iridium LLC与2000年后Iridium Satellite/现Iridium Communications并非同一权益主体；2026交易尚未完成
- 下一步：评审“不是技术复活，而是资本结构与客户重写”结构
