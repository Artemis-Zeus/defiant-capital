## 覆盖与方法

| 层面 | 已完成 | 限制 |
|---|---|---|
| 原片 | 直接读取四个 1920×1080 H.264＋AAC 文件并登记哈希 | 不在仓库复制第三方完整作品 |
| 文本 | 四片完整音轨 ASR；烧录字幕约每秒 OCR，共 9,621 个时点；全文通读并回查结构 | 专名、数字、引语仍需人工回片校订 |
| 画面 | 四片共抽取并逐张查看 803 个时间采样帧；E001 开头另做加密观察 | 不是连续逐镜审片，短镜头和转场可能漏看 |
| 自动变化点 | 仅用于寻找复核位置 | 对编码、灯光和动画敏感，不作为镜头数或节奏统计 |
| 声音 | 音轨用于机器转写 | 当前模型接口不能直接听音，音色、重音、停顿、配乐和音效仍未验证 |

原始视频、音轨、机器转写和接触表保存在仓库外的临时分析目录；仓库只保存原创分析、必要短摘录、链接和时间定位。

## 跨片已重复的方法

- 四片都先呈现一个具体异常状态，再补题材和背景；参照事件只是 E001 的一种实现。
- 背景只保留后来会改变选择的部分：预算、土地开发经验、技能和人脉、航空安保改造。
- 长篇靠一串可回答的问题推进；每个答案同时产生下一项约束。
- 早期细节会在动作层回收，改变人物或机构下一步，而不只做词语呼应。
- 商业段借紧邻正文的词、物件或人物关系进入，再用明确时间、地点或处境恢复主线。
- 结尾回到开头并改变开头的解释：城市尺度、项目返工、人物自我神话或喜剧转悲剧。
- 画面素材比例随栏目变化，稳定规律是任务分工：实景／档案给物理和时代锚点，影视片段给角色动作，动画给长对话和可控演绎，照片／文书给身份或事实锚点，屏幕字给评价和压缩信息。

这些方法达到“跨片重复”，尚未达到“条件明确”或“迁移验证”。两条组织片与两条人物片已显示明显分支，不能压成一套固定模板。
