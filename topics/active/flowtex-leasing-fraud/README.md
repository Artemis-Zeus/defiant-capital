# FlowTex：纸面资产、真实现金

## 一句话故事承诺

FlowTex把水平定向钻机卖给融资方再租回，真实业务与按期租金让交易看起来正常；但官方文件所称约3000套钻机并不存在，融资检查只要继续围绕编号、合同和被展示的少量机器打转，纸面资产就能持续换成真实现金。

## 核心机制

融资租赁把“设备是否真实存在”和“承租人是否持续付款”分给不同环节验证。只要新融资能覆盖旧租金，付款正常就会反过来证明资产好像存在，形成以现金流掩盖资产确权失败的循环。

- 最大缺口：实际存在机器数量在公开二手来源中有181、220、270等冲突；具体换牌/搬运检查手法尚缺可精确定位的一手刑事判决全文
