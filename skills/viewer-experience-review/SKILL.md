# Review the viewer experience

Read `docs/narrative-production-standard.md` (门禁 sections), `docs/douyin-standard.md` if reviewing a douyin episode, the topic's `07-risk-review.md`, the outline (`05-story-outline.md`), the script (`script/master.md` or `script/douyin.md`), `script/shots.md`, and `06-visual-assets.md`.

## Walk the episode as a viewer

1. **Two-track read.** For each segment, read the narration line and its shot together. You are scoring what a viewer sees AND hears; text alone is not the artifact.
2. **Opening.** Within the first 30—45s (douyin) or first 60s (long video): does the absurd scene land before abstract macro talk? Is there at least one concrete visual noun on screen? Would a scrolling viewer stop? The spoken question must be scene-carried, never a narrator rhetorical question.
3. **Retention pulse.** Every 20—30s of narration: is there an on-screen action, a changed situation, a concrete example, or a new question? Report the longest stretch without one, with its anchor.
4. **Reference frames across tracks.** For every place the narration deliberately omits scale, place, or role context, confirm `shots.md` supplies it on screen (caption card, map, archive photo). Omitted in both tracks = blocking gap. Conversely, an on-screen reference the narration never uses must still be verifiable against the evidence matrix.
5. **Mechanism caps.** Long video: one mechanism segment ≤90s. Douyin: ≤40s per segment, ≤120s total. After each mechanism segment, the next shot must return to a person acting.
6. **Metaphor and meme load.** Two borrowed images serving the same beat within ~20s count as dilution; flag for the narrator to cut one. Memes must serve memory or understanding, not stack.
7. **Attribution layer.** Legal qualifiers ("指控/表示/和解/当时") must survive in narration or on-screen text. Check each high-risk sentence against `07-risk-review.md`; a qualifier dropped from both tracks is blocking.
8. **Jumps and cuts.** Wherever narration jumps time or hard-cuts (e.g., cold open into a flashback), the shot list must carry the jump with a date card, freeze, or match cut. An unnarrated jump with no visual bridge is blocking.
9. **Ending.** One character fate, one thematic judgment, one comment prompt. Stacked uplifts or a second ending = flag.

## Output

- A segment-located issue list: each item = anchor (chapter / 镜号 / first spoken line), track (口播 / 画面 / 双轨), severity (阻塞 / 建议), and a concrete fix.
- 阻塞 means a gate violation: mechanism cap exceeded, reference frame missing from both tracks, legal qualifier dropped from both tracks, visual pretending to be archival footage, unnarrated time jump without visual bridge.
- Do not re-audit facts. Evidence mapping belongs to the research layer and `write-capital-story`. If a fact looks wrong, route it back with its anchor; do not fix it in this pass.
- Close with a verdict per gate and the three highest-leverage fixes.
