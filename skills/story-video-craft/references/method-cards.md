# 方法卡

这些方法来自四条成片的跨样本分析。它们是条件化工具，不是固定模板。每次只选能解决当前观众问题的方法，并让题材证据决定具体写法。

## M01 具体异常开场

**用于：** 题材年代远、人物陌生、机制复杂，直接介绍会让观众先背背景。

**准备：**

- 一个已核验的具体时间或环境；
- 一个能被画面或简单旁白呈现的对象；
- 一项正在进行的动作；
- 一个与常态冲突的结果。

**操作：**

1. 第一句优先写时间／环境和动作，不写主题判断。
2. 第二步让异常发生。
3. 给一个局部、可追踪的目标，例如设备能否恢复、门能否打开、条件能否形成。
4. 让局部问题自然指向更大的历史或机制问题。
5. 问题成立后再报人物、机构和栏目。

**验收：**

- 观众不懂背景也能复述异常；
- 删除“今天我们讲”类句子，开场仍成立；
- 开场没有依赖未证对话；
- 结尾能回到这项异常。

**失效：**

- 为猎奇从结局截取一幕，却在正文很久都不兑现；
- 异常本身需要三分钟解释；
- 只有形容词，没有人、物、动作和结果；
- 把法律定论或人物身份故意藏起来。

## M02 背景只为后续选择服务

**用于：** 有大量历史、机构、生平或行业资料，容易写成百科前言。

**操作：**

1. 为每条背景材料填写“后来改变了谁的哪个选择”。
2. 按回收位置分组，而不按百科类别分组。
3. 第一次承担戏剧功能前，只给最小参照。
4. 回收发生时，用具体动作再次激活背景。
5. 没有回收的材料删除、移到画面或研究附录。

**最小参照：**

- 实体：它是什么、体量如何；
- 时代：当时有哪些现实约束；
- 数字：相对什么才显得大或小；
- 选择：当时真正存在的替代方案。

**验收：** 每段背景后都能补出“所以后来他／项目只能……”，且该句有证据。

**失效：** “为了让观众更了解时代”成为唯一保留理由。

## M03 选择—暂时解法—遗留约束

**用于：** 财政、治理、融资、工程或制度背景需要成为故事动力。

**操作：**

1. 写当前问题。
2. 写当时可见的方案和诱因。
3. 写实际选择。
4. 写它怎样暂时解决当前问题。
5. 写它留下的更窄条件。
6. 下一段从这个条件开始。

**句法骨架仅用于检查，不直接照抄：**

> 为了解决 A，承载者选择 B。B 让眼前的 C 暂时消失，却同时失去了 D。下一次变化发生时，他只能在 E 和 F 之间选。

**验收：** 删除机制术语后，观众仍能复述“为什么当时会选、后来少了什么选择”。

**失效：** 用后来信息责怪当事人，或把多个独立原因压成一条道德因果。

## M04 答案生成下一题

**用于：** 中段只有“然后、随后、与此同时”，事件很多但推进感弱。

**操作：**

1. 给当前段一个可回答的问题。
2. 通过行动给答案。
3. 从答案中找新限制：资源、时间、关系、程序、技术或误判。
4. 把新限制改写成下一段的目标。
5. 若答案没有产生新条件，删掉该段或并入上一段。

**章间测试：**

> 因为上一章发生了 ______，所以这一章必须解决 ______。

填不出来就重排。

**失效：** 章末另加空泛问句，而正文答案与下一章没有关系。

## M05 可检验的阶段目标

**用于：** 长视频中段缺少具体期待，只能不断宣告风险升级。

**目标类型：**

- 期限：某时能否恢复、完成；
- 条件：谈判能否形成可执行方案；
- 证据：调查能否确认入口或身份；
- 资源：钱、人、设备、许可是否到位；
- 关系：某一方是否继续支持。

**操作：**

1. 明确人物当时相信的目标。
2. 展示至少一项支持条件和一项威胁条件。
3. 到达检验点时明确结果。
4. 若失败，指出哪一条件变化；若成功，指出成功制造的新问题。
5. 下一阶段换一种主要机制。

**失效：** 连续用作者事先知道、人物却不可能知道的倒计时；反复靠隐藏同一种信息制造失败。

## M06 抽象机制落到可观察后果

**用于：** 技术、金融、法律或行政机制不易口播。

**三步：**

1. 正常功能：它本来解决什么；
2. 变化动作：这次哪一步没有发生、被绕过或改变；
3. 人物后果：谁现在少了什么资源，只能做什么。

**画面选择：**

- 关系结构交给原创图解；
- 空间交给地图；
- 数字分量交给比较图；
- 真实行动交给可核影像；
- 无原始影像的对话用明确标注的示意。

**验收：** 不使用术语，观众也能说出“这一步为什么改变了下一步”。

**失效：** 用比喻替代事实，或比喻引入错误因果。

## M07 早期细节的行动性回收

**用于：** 背景、物件、数字和规则很多，观众难判断哪些值得记。

**操作：**

1. 首次出现时说明细节当下的最低含义。
2. 在架构稿登记回收位置。
3. 回收时让它改变动作、资源、判断或风险。
4. 若只产生一句文字呼应，降低其铺垫权重。

**回收测试：**

- 谁因这个细节能做／不能做什么？
- 若删去首次出现，后文是否难以理解？
- 若删去回收，首次出现是否显得多余？

两个删除测试都无影响时，删去。

## M08 人物生平转行动资源

**用于：** 人物题材需要解释能力、欲望和误判。

**资源分类：**

- 技能：后来实际完成了某动作；
- 人脉：后来提供人员、许可或信息；
- 身份／资格：后来打开或关闭一条路径；
- 激励：后来改变选择，但必须有证据；
- 限制：后来使某方案不可行。

**操作：**

1. 先让观众看到人物当前行动或异常。
2. 只在答案需要时回溯。
3. 每段生平末尾不评价人格，直接回到它怎样影响后文选择。
4. 同一经历不要同时解释所有行为。

**风险：**

- 当事人说法只能写为其声称；
- 不自行诊断；
- 政治、犯罪和家庭经历须精确归因；
- 不把苦难写成“必然犯罪”的原因。

## M09 角色接力

**用于：** 危机或群像题材必须多次换人。

**操作：**

1. 新角色接到上一角色制造的具体局面。
2. 首次出现立刻给目标和手边资源。
3. 只讲完成当前动作所需的身份。
4. 离场前改变下一角色的条件。
5. 共享时钟发生回退或并行时，给明确时间坐标。

**验收：** 能画出“角色 A 的输出 → 角色 B 的输入”。

**失效：** 只是按部门、地域或职位轮流介绍。

## M10 画面任务路由

**用于：** 防止逐句寻找同义素材，也防止影视梗挤占证据。

**先标任务，再找素材：**

| 任务 | 优先素材 | 不能做什么 |
|---|---|---|
| 证据 | 原始文书、档案、可核现场／采访 | 不用剧情片冒充 |
| 定位 | 地图、年份卡、身份条、实体全景 | 不把大量坐标全塞旁白 |
| 解释 | 原创流程、结构图、金额比较 | 不用无关工业空镜假装解释 |
| 演绎 | 原创动画、明确标注的影视示意 | 不让演员被误认真人 |
| 评价 | 补充字、反应画面、短视觉反差 | 不遮挡法律限定和关键数字 |

**验收：**

- 静音能否认出人物和阶段；
- 闭眼能否听懂主因果；
- 旁白省略的信息是否真的由画面承接；
- 每项素材是否有来源与权利状态。

**失效：** 把素材片名当授权，或因素材丰富改变事实重心。

## M11 开头意义回扣

**用于：** 结尾容易变成损失数字、后续名单和空泛升华。

**操作：**

1. 开头选一个尚未被完整解释的动作、物件、态度或判断。
2. 中段让因果链提供新解释。
3. 结尾回到同一对象，不逐字重复开头。
4. 先交代命运，再给一次判断并停止。

**验收：** 观众看完后对开场的解释发生变化；若只是“原来事情很严重”，变化不够具体。

**失效：** 靠音乐或大词宣布升华，中段没有支持新含义。

## M12 重复配置的意义翻转

**用于：** 两次相似事件、方案、谈判或危机可互相解释。

**操作：**

1. 第一次建立观众预期。
2. 第二次保留可识别的地点、角色、物件或动作。
3. 明确改变一个决定性条件。
4. 让新结果迫使观众修正第一次的情绪或判断。

**验收：** 能准确说出“相同项、变化项、旧解释为何失效”。

**失效：** 只提高规模或重复创伤；变化条件没有证据。

## M13 商业邻接桥与主线重载

**仅在用户要求商业段且合规材料齐备时使用。**

**进入：** 从广告前一句的词、物件或人物关系自然转义，同时明确商业身份。

**内部：** 问题／场景 → 可验证证明 → 功能 → 使用情境 → 条件／限制 → 行动。

**退出：** 用年代、地点、人物处境或未解目标重新加载主线。删除广告后，正文必须语义连续。

**失效：**

- 用顺滑桥接隐藏广告性质；
- 在关键事实尚未建立时插入过长商业段；
- 健康、销量、奖项、用户评论或肖像没有材料；
- 借悲剧人物或脆弱关系强行转商品。

## 选择方法的最小原则

每个方法必须对应一个明确问题。不要为了“像某种风格”同时堆叠异常开场、密集反转、长动画、黑色幽默和回扣。若无法写出“本方法解决的观众问题”，就不用。
