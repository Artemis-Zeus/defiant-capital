# 叙事分支选择

只在需要确定故事承载者或发现章节发散时读取。分支是组织因果的工具，不是栏目模板。

## 一分钟选择法

分别补完三句话：

1. 人物句：因为【某人】连续选择了什么，局面才从 A 到 B。
2. 项目句：因为【某机构／项目】不断吸收了什么承诺与约束，局面才从 A 到 B。
3. 危机句：因为【同一时钟／空间／资源危机】迫使多方接力行动，局面才从 A 到 B。

证据最完整、删去其他角色后仍能解释主因果的一句，就是主分支。若两句同样成立，选择观众最容易持续追踪的承载者，另一句降为机制副线。

## 删除测试

对候选承载者问：

- 删除它，结局还会以相同方式发生吗？
- 它是否在至少三个关键节点作选择、吸收约束或改变他人条件？
- 它能否承接开场异常、最大反转和最终代价？
- 研究是否证明了它每次行动前可见的信息？

前两问答“会／否”时，不适合作为承载者。

## 人物分支

### 适用条件

- 同一人物在多个阶段持续行动；
- 目标、资源或欲望可由证据描述；
- 人物技能和误判能解释行动，但不需要虚构心理；
- 结局主要落在该人物及其直接关系上。

### 强制台账

| 阶段 | 人物想得到什么 | 手里有什么资源／技能 | 当时知道什么 | 选择 | 立即结果 | 暴露的新限制 |
|---|---|---|---|---|---|---|

### 生平筛选

生平事实只有满足下列之一才进入：

- 后来变成一项可观察技能；
- 提供关键人脉、权力或资格；
- 形成有证据的目标或激励；
- 限制人物能选择的方案；
- 在后文被人物主动提及并改变行为。

“塑造了性格”“埋下伏笔”“注定了命运”不算回收。必须指出具体行动。

### 推荐结构

当前异常 → 观众先观察行动 → 必要生平回溯 → 资源／技能进入选择 → 第一轮结果 → 缺陷或外部条件改变解释 → 关系／制度反转 → 代价 → 回扣开场。

不要求固定章数，也不要求人物必然失败。

### 常见失败

- 从出生开始顺叙，直到很晚才进入题目承诺；
- 用童年创伤单因果解释成年行为；
- 把诊断、政治立场或人格形容词当作行动原因；
- 为保持“狠人”形象删掉失败、偶然和他人贡献；
- 将所有配角写成主角能力的证明工具。

## 组织／项目分支

### 适用条件

- 事件跨越多人或多年，单一自然人无法覆盖；
- 同一机构／项目持续保留目标、预算、承诺、设计或法律身份；
- 每一阶段的人物选择都会改变该项目下一阶段的条件；
- 结局主要表现为成本、范围、能力、合法性或公共关系的变化。

### 把项目写成可追踪状态

每个节点至少更新一项状态：

| 状态 | 要回答的问题 |
|---|---|
| 目标 | 这一阶段项目被要求解决什么？ |
| 范围 | 新增了什么承诺，删除了什么方案？ |
| 资源 | 钱、时间、土地、人员、技术、许可如何变化？ |
| 退出成本 | 为什么越来越难停止、缩小或改道？ |
| 外部标准 | 法律、生态、技术或市场规则怎样变化？ |
| 承担者 | 谁获得收益，谁承担延期、风险或损失？ |

### 推荐结构

当前荒谬结果 → 回到最初问题 → 一个看似合理的方案 → 需求／承诺逐项叠加 → 退出条件收窄 → 外部标准变化 → 旧成果失效或代价暴露 → 回到当前结果。

### 人物进入规则

人物首次出现时必须立刻改变项目状态：批准、加需求、承诺资金、提出警告、阻止、裁决、退出或承担代价。只提供职务说明、不改变状态的人物留在画面身份卡或研究层。

### 常见失败

- 变成机构沿革和术语清单；
- 用“体制”替代具体决策者、程序和资源；
- 把后来的成本当成当时人人可知；
- 把所有延期压成一个责任人的动机；
- 项目状态没有变化，章节只按年份排列。

## 危机／群像分支

### 适用条件

- 单次危机内有多个行动中心；
- 角色共享一个明确时钟、空间或资源约束；
- 前一角色的决定会改变下一角色手边条件；
- 任一角色都不足以独立承担全片，但危机本身有连续状态。

### 接力表

| 角色 | 接到的局面 | 手边资源 | 采取动作 | 交给下一角色的新局面 |
|---|---|---|---|---|

换人前必须回答“为什么现在轮到他”。无法回答的切换就是支线。

### 推荐结构

危机触发 → 建立共同期限／资源 → 决策中心判断 → 执行者遭遇具体限制 → 现场事实反证上层判断 → 资源进一步耗尽 → 阶段目标改变 → 代价结算。

### 常见失败

- 按机构轮流介绍；
- 时间重置没有明确坐标；
- 用少数角色推定整个群体动机；
- 配角故事可任意交换，删除后不影响局面；
- 责任争议被剪成虚假对话。

## 混合题材怎么处理

允许副线，不允许多个主分支并列：

- 人物＋公司：人物作选择，公司机制解释选择代价。
- 项目＋政治人物：项目承载状态，人物只在改变状态时进入。
- 人物＋危机：人物为主角，危机只提供阶段约束。
- 群像＋制度：危机为承载者，制度只解释手边资源为何不足。

每章标题若开始轮流使用人物名、机构名、机制名，说明分支正在漂移；回到因果台账按“谁把什么新局面交给谁”重排。
