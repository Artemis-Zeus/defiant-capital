# 调用示例

## 最短调用

```text
使用 $story-video-craft 和 $write-capital-story，
读取 topics/active/<slug> 的完整研究材料，
先修订 05-story-outline.md，再生成平台中性的 script/master.md 初稿。
完成事实闭环、因果、口播和原创性检查。
```

## 推荐的完整调用

```text
使用 $story-video-craft 和 $write-capital-story，
把 topics/active/<slug> 已核验的研究材料转成一份长视频母稿初稿。

要求：
1. 写作前执行研究退出门禁；关键行动、当时所知、结局、核心数字或法律状态缺证时，先列阻塞，不得补造。
2. 选择人物、组织／项目或危机／群像中的一个主分支，并给出一句话连续因果链。
3. 先更新 05-story-outline.md：建立因果台账、信息释放顺序、章节目标、C### 绑定、铺垫回收和画面任务。
4. 再写 script/master.md：纯净旁白，平台中性，正文不含编号、URL、镜头指令或平台互动；每章末只列来源名称和年份。
5. 开场从具体异常状态进入，不口头自问自答；背景只保留会改变后续选择的材料；每章答案必须产生下一项问题或限制。
6. 机制段按“正常功能—变化动作—人物后果”写，并尽快回到行动。
7. 结尾先落人物／项目命运，再回到开场并赋予新含义，只保留一次主题判断。
8. 默认不加入广告。
9. 只吸收结构、信息释放和声画分工方法，不复制任何参考创作者的措辞、口头禅、固定梗、标题句法、角色形象或声音身份。
10. 运行 audit_claims.py 和 audit_voiceover.py，按 skill 的验收格式汇报。

目标成片时长：<分钟或“由材料决定”>
希望重点：<例如机制清楚、人物选择、悬念克制、黑色幽默>
```

## 组织／项目题材

```text
使用 $story-video-craft 的组织／项目分支和 $write-capital-story，
为 topics/active/<slug> 生成母稿初稿。

把 <公司／机构／项目> 作为唯一故事承载者。
逐章更新目标、范围、资源、退出成本、外部标准和承担者。
人物只在批准、加需求、融资、警告、阻止、裁决、退出或承担代价时进入。
避免写成机构沿革或机制分类；每个历史背景必须在后文改变项目状态。
```

## 人物题材

```text
使用 $story-video-craft 的人物分支和 $write-capital-story，
为 topics/active/<slug> 生成母稿初稿。

先从主人公当前的具体异常行动进入，再按需要回溯。
生平只保留后来成为技能、人脉、目标、误判或限制的材料，并标出回收位置。
严格区分可观察行动、当事人自述和分析判断；不自行诊断，不用童年或身份解释一切。
```

## 危机／群像题材

```text
使用 $story-video-craft 的危机／群像分支和 $write-capital-story，
为 topics/active/<slug> 生成母稿初稿。

用同一时钟、空间和资源危机维持主线。
建立角色接力表：上一角色的输出必须成为下一角色的输入。
时间回退或并行叙事必须有明确口播坐标，并在架构稿登记视觉转场。
```

## 只做架构，不写母稿

```text
使用 $story-video-craft，只更新 topics/active/<slug>/05-story-outline.md。
完成故事合同、分支选择、因果台账、信息释放图、章节卡、C### 绑定、三项关键回收、结尾回扣和画面任务。
不要生成 script/master.md。
```

## 改写已有母稿

```text
使用 $story-video-craft 和 $write-capital-story 审查并改写
topics/active/<slug>/script/master.md。

先列出：
- 断裂的因果节点；
- 没有回收的背景和数字；
- 只介绍身份、不改变局面的配角；
- 口头自问自答和报告腔；
- 没有证据绑定的动机、对话和责任判断；
- 第二结尾；
- 可能接近特定创作者表达的句子。

先修 05-story-outline.md 的结构和 C### 绑定，再改母稿。保留用户已有的可靠内容，不重写无关章节。
```

## 包含商业段

```text
使用 $story-video-craft、$write-capital-story，并在母稿中设计一个可删除的独立商业段。

商品与合规资料位于：<路径>。
先核对健康／性能、销量、奖项、评论、肖像、价格和售后主张。
用紧邻正文的词、物件或人物关系进入，同时明确商业身份。
退出后一两句重新加载年代、地点、人物处境或未解目标。
删除商业段后主线必须无语义缺口。
```

## 指定重点但避免错误指令

可以写：

```text
增强行动因果、信息反差和克制的黑色幽默。
```

不要写：

```text
完全模仿某创作者的口吻、句式、梗和配音。
```

若用户使用后一种表述，仍只提取高层方法，并明确产出为本项目原创表达。
