# 视频创作方法研究与 skill 提炼计划

版本：V0.3  
日期：2026-09-05  
状态：执行中；E001—E004 已完成四片文本与画面跨样本底稿，实验版 `story-video-craft` skill V0.1 已建立并接入仓库写稿流程与题材模板；声音听审、反例采样、原创迁移和稳定版验收尚未完成。

## 1. 目标与本轮范围

以小约翰可汗的公开视频为样本，系统研究选题、文案、口播、画面、声音、剪辑及包装如何共同构成观众体验。逐步形成有样本依据、适用条件和检验方法的创作 skill，服务“逆天的资本”的原创视频生产。

这里的“蒸馏”指把成片中可观察的创作决策转化为可执行方法，不涉及训练模型权重，也不声称能从成片还原作者完整的知识、直觉和团队流程。

研究设计已完成，四片 V0.2 分析见 `topics/active/creator-study-xiaoyuehan/`；当前已形成强指导性的实验 skill，完成反例、声音和原创迁移后再升级为稳定版。

已分析两条“神奇组织”和两条“硬核狠人”，合计约 160 分 20 秒。四片均直接读取用户指定的本地 MP4，完成全文机器辅助通读和全片画面采样；共检查约每秒字幕 9,621 个时点与 803 个定时画面帧。当前接口不支持音频输入，因此主观听审仍明确缺失。

研究遵循 `docs/narrative-production-standard.md`、`docs/research-and-sources.md` 等现有规范。借用 `skills/write-capital-story/SKILL.md` 的结构与口播分层方法，以及 `skills/viewer-experience-review/SKILL.md` 的声画联合检查方法。

## 2. 结论必须分层

| 层次 | 可以形成的结论 | 必须保留的限制 |
|---|---|---|
| 成片观察 | 某时间段出现了什么措辞、停顿、画面或声音变化 | 必须定位到原片；缺少哪种模态就不能判断该模态 |
| 作用解释 | 这种安排可能如何影响理解、预期、情绪或记忆 | 标为分析判断，列出替代解释 |
| 跨片规律 | 某做法在什么样本、什么情境下重复或不出现 | 列出分母、例外与题材条件 |
| 幕后流程假说 | 成片可能需要哪些研究、写作或剪辑步骤 | 未见访谈或工作材料时，不当作作者真实流程 |
| 本项目方法 | 在我们自己的制作中怎样应用、怎样检查 | 通过新题材试写、试录和分镜检验 |

描述样本时先记录它实际怎样做，再与本项目规则比较。不能因我们的规则要求单主角、特定开头或机制时长，就先把参考视频改造成符合这些规则的样子。

播放量、点赞和评论只能提供有限的外部反馈。没有后台留存数据时，不绘制“真实留存曲线”，也不宣称某次剪辑或某句文案导致了播放增长。叙事张力与认知负担图须注明是分析者标注。

## 3. 分阶段执行

| 阶段 | 工作 | 交付物 | 完成标准 |
|---|---|---|---|
| 0：可读性与记录方法校准 | 用开头 3—5 分钟试做字幕、画面、音频对齐，检查能否取得可分析的声音 | 访问能力表、试标片段、字段修订 | 能指出所见、所闻、无法确认之处；时间戳可回查 |
| 1：首片整体通读 | 连续理解整片，先记录故事承诺、人物/冲突中心、章节、情绪与疑惑，再做细读 | 全片结构图、信息释放顺序、观看覆盖表 | 整片有连续覆盖，未读区间显式列出 |
| 2：首片精读 | 分别细读文案、口播、画面声音，再回到声画组合检查 | 分段观察、逐镜记录、口播分析、技法卡、例外与弱点 | 每项主要结论都能回到具体区间；所有关键转折已复核 |
| 3：首片方法假说 | 把观察转成条件化的操作步骤，区分特定题材做法与候选规律 | 单片能力图谱、候选规则、后续取样需求 | 不把一次出现写成账号普遍规律；每条规则可被新样本推翻 |
| 4：跨片比较 | 按栏目、年代、题材和素材条件逐片扩展，并专门找反例 | 样本矩阵、规律版本、例外库 | 跨片重复有出处，冲突有解释或保留未决 |
| 5：迁移试验 | 使用本仓库已核验的新题材，完成开场、复杂解释、转折、结尾及对应镜头的小样 | 同事实不同处理的对照稿、试录、镜头小样与评估 | 改善可被描述与复核；事实、原创性和制作条件均通过 |
| 6：skill 编写与验收 | 把稳定方法编成输入要求、分步操作、条件分支、输出格式和审查清单 | skill V0.1、参考索引、测试任务、变更记录 | 在未用于提炼的样本及新题材中通过检验；不足有适用边界 |

首片不设篇幅上限，以覆盖与可回查为准；正文结论、明细证据和规则分层呈现，避免把所有记录挤进一篇难以复用的长文。

## 4. 分析维度

以下均为待研究的问题，不是对这个账号已经得出的风格结论。

| 维度 | 具体研究内容 |
|---|---|
| 选题与切口 | 事件的异常性、冲突中心、知识门槛、资料与画面可用性；标题承诺是否在片内兑现；为何从某人、某场面或某结果进入 |
| 故事架构 | 冷开场与正文关系、顺叙/倒叙、章节边界、主线与支线比例、转折、铺垫回收、结尾如何终止 |
| 信息释放 | 哪些信息先给、延后给或略去；观众何时知道结果；悬念、误判与重新理解如何发生 |
| 人物组织 | 首次出场方式、目标与资源、连续行动、关系变化、配角功能、群像如何保持清晰；叙述者如何评价人物 |
| 背景与机制 | 陌生国家、机构、金额和制度的参照系；抽象概念怎样转为行动；哪些信息留给画面；历史事实与修辞如何区分 |
| 段落与句子 | 段落任务、句长变化、换气单位、动词密度、具体与抽象词、书面语与口语切换、数字与专名负担、转场句功能 |
| 幽默与修辞 | 反差、类比、反讽、夸张、语体错位、重复回扣、包袱铺垫与落点；依赖哪些先验知识；笑点是否抢走事实重点 |
| 口播表现 | 实际语速变化、重音、停顿、尾音、音高与能量变化、冷静与激动的切换、句内和段间节奏；区分原声、配音和旁白 |
| 素材选择 | 人物照、新闻、档案、地图、文书、电影片段、梗图、示意动画等分别承担证据、定位、解释、情绪、笑点或过渡功能 |
| 素材来源与改造 | 可见出处、年代与事件对应关系、裁切、推拉、定格、标注、拼贴；素材身份与许可状态分别核查 |
| 字幕与画面文字 | 逐字字幕与补充信息的分工、强调词、颜色字号、位置、遮挡、阅读时间、人物身份条、年份卡与数字图形 |
| 剪辑与声画配合 | 镜头长度与变化、静态图运动、切点与语义节点、动作/音乐/笑点同步、反应镜头、视觉回扣、转场桥接 |
| 音乐与音效 | 背景音乐的进入退出、音量与旁白关系、情绪功能、静默、音效落点、原声片段的使用；不凭印象认定曲名或授权 |
| 观众体验 | 每段让观众知道、期待和感受到什么；认知负担、信息重复、迷失、喘息点、情绪转换与看完后的主要记忆 |
| 包装与商业表达 | 标题、封面、简介、章节、互动、系列关系；若有商业段，分析其位置、提示及与叙事的衔接；不可见则标不适用或未观察 |
| 制作可行性 | 做法需要的证据、素材、配音和剪辑投入；可用替代方案；哪些依赖账号长期积累的观众默契 |

对标志性口头禅、固定梗、标题句法等，可以描述其功能与出现位置。生成用规则抽象到结构、信息控制、对比和口头节奏，不将个人标志性表达编成复刻指令，也不以声音身份复制为目标。

## 5. 记录粒度与字段

采用三种互相引用的记录单位，不用均匀截图代替整片分析：

1. **结构段**：以一次叙事任务或局面变化为界，长度随内容变化。记录这段的进入条件、信息增量、离开时的局面。
2. **口播单位**：按句子、意群和实际换气细分；对关键笑点、转折、解释与结尾记录声学表现。
3. **镜头/画面事件**：每次剪切或有叙事意义的画面变化建记录；同一镜头内字幕、地图标记或音效变化可建子事件，不把每帧当成一个镜头。

每个结构段连接对应口播和镜头记录。每 20—30 秒做一次体验检查，作为检查窗口，不当作作者实际使用的创作公式。

最小记录字段：

| 字段 | 内容 |
|---|---|
| 定位 | 样本编号、起止时间、段落/镜头编号、原片链接 |
| 话语 | 该段内容概述、叙事功能、核验所需的最小引语；不以完整转录替代原作 |
| 声音 | 实际听到的语速、停顿、重音、音乐和音效；记录获取方式及不确定性 |
| 画面 | 素材类型、可见内容、屏幕文字、运动与切换、是否可能为替代画面 |
| 声画关系 | 同义强化、互相补充、反差、提前提示、延迟兑现或无关；说明判断依据 |
| 观众状态 | 进入前已知什么，本段新增什么，离开时期待什么；注明分析者推断 |
| 分析 | 观察事实、作用解释、替代解释、可迁移方法、失效条件 |
| 证据 | C###—S###、来源精确位置、访问日期、复核状态、声音/画面覆盖状态 |

量化只用于回答具体问题：例如章节时长、专名首次引入密度、镜头长度分布、笑点间隔、配乐切换。语速须说明字数口径、时间窗口和是否扣除停顿；镜头统计须定义切分规则。少量片段的数字不能标成全片统计，估算不能伪装成精测。

## 6. 访问与证据方案

优先使用已登录的原视频页面，核对播放器字幕、可见画面与真实音轨是否可供分析。字幕可以辅助理解措辞，但自动字幕须标注误识别；画面内字幕与播放器字幕须区分。

**技术可行性是阶段 0 的首要交付。** 当前已确认可读取页面状态与截图，尚未证明工具能够直接取得并分析整段音频。浏览器在播放，并不等于模型听到了声音。

若现有路径不能提供音频，保留口播与声音分析为未完成，继续独立的结构和画面工作，同时明确需要可供分析的用户有权提供的音视频材料。不能凭字幕推断音色、情绪重音或配乐；不能把静帧采样写成连续观看。需要新增工具时先查现有能力，再提出具体依赖。

覆盖表分别记录文本、画面、音频的已读区间、缺失区间与复核情况。只有三路证据达到对应分析所需覆盖，才能交付“完整的文案、口播、素材分析”。

原视频对“成片采用了某种处理”是直接证据；对“片中历史事件确实如此”只是线索。后者若进入本项目作品，另按研究 skill 建立历史事实证据，不能由参考视频替代核验。

公开仓库仅保存原创分析、链接、必要短摘录和时间定位。完整视频、音轨、连续大段转录、字幕文件、截图及素材包不因登录而获得公开归档许可；素材只登记链接、用途与版权状态。发现画面出处也不等于获得使用权。

## 7. 多片取样与规则升级

建议先分析 1 片，随后补至 3—4 片，再视差异扩展到 6—8 片；另预留约 2 片作未参与规则提炼的检验样本。数量是起始研究预算，不是证明风格的统计阈值，后续按新发现和成本调整。下一批具体链接在首片之后选择。

取样考虑：同栏目与不同栏目、人物主导与组织/事件主导、较早与较近作品、素材丰富与素材稀缺、偏幽默与偏沉重、信息量和篇幅差异。不只选择高播放作品，也不预设全部视频都符合一种风格。

每加一片都回答四件事：验证了哪些假说、出现了哪些新方法、反驳了哪些旧规则、哪些差异能由题材/时期/系列解释。

候选方法采用独立的成熟度标记：单片观察 → 跨片重复 → 条件明确 → 迁移验证。成熟度不能代替仓库的事实状态，也不能把多条同作者视频算成历史事实的多源独立验证。

同一方法在多片重复时，记录“适用场景出现次数 / 实际检查过的适用场景数”，不要只列成功例。未出现、效果可疑和本项目不适用的样本进入例外库。

当不同类型的新样本主要用于修正规则边界、很少再引入新的关键机制，并且预留样本检验与原创试作均通过时，再考虑稳定版。仍有分歧则保留条件分支，不靠增加强制规则掩盖分歧。

## 8. 每条规则如何转成可执行能力

一张技法卡至少包含：

- 要解决的观众问题，以及输入条件；
- 样本中的观察与反例，关联 C###—S### 和时间定位；
- 可能的作用机制，以及判断的可信范围；
- 实际操作步骤和可选择的处理方式；
- 文案、口播、画面与声音如何配合；
- 适用情境、失效情境、素材和制作成本；
- 验收问题及常见失败；
- 基于已核验新题材的原创应用示例。

“多用反差”“口语化”“节奏紧凑”只能作为分类标签，不能直接作为 skill 的操作指令。规则需要回答：在哪里用、根据什么选择、怎样做、怎样知道做错了。

试验示意（不是本视频的分析结论）：若假说是“先建立金额参照会让后续选择更容易理解”，使用同一事实包制作带参照与缺参照的小样，检查观众能否复述金额分量、人物选择与代价。一次只改变主要待测因素。

## 9. 迁移验收与 skill 形态

先做四类短任务：开场、复杂机制解释、转折、结尾；每项同时给旁白和镜头。口播表现须经实际试录后再评价，有条件时形成包含声音和画面的成片小样。短任务通过后再扩展到完整长视频。

采用同事实包、相近时长和相同制作条件的对照；记录分析者评估和用户观看反馈，尽可能在不知道方案来源的情况下比较。没有真实观众时，明确标注为编辑评估，不声称已经证明留存提升。

验收维度：

| 维度 | 检验问题 |
|---|---|
| 理解 | 能否说清人物、目标、选择、因果和核心金额分量？ |
| 继续观看动机 | 每次转折是否留下具体期待，之后是否兑现？ |
| 口播 | 是否可自然换气、重点可听出、笑点和解释不互相打断？ |
| 声画分工 | 关键信息是否被任一路承接，字幕是否有时间读完，声音是否干扰理解？ |
| 事实与原创 | 是否保持事实限定语，是否避开原作特有措辞、固定梗和表达组合？ |
| 可制作 | 所需素材能否合理获得，替代素材是否明确，执行成本是否匹配项目条件？ |

实验 skill 路径为 `skills/story-video-craft/SKILL.md`。核心文件提供触发条件、必需输入、工作步骤、条件分支与退出检查；详细技法卡、研究依据、验收门禁、调用示例和测试任务按需加载，避免每次写作读入全部原始分析。V0.1 已完成八类测试输入的静态规则覆盖；这只证明指令完整，生成质量仍须由原创题材迁移、试录和观感评估验证。

该 skill 与现有技能分工：研究技能管事实；新 skill 管叙事和声画创作决策；写稿技能管架构稿、口播稿与事实绑定；观感技能检查观众侧产物。生成用部分以可迁移方法命名，研究索引保留作者和视频归属。
