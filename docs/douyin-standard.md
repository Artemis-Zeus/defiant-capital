# 抖音主站内容规约 V1.0

本规约收束此前散落在 `README.md`、`docs/project-spec.md` §7.2、`docs/editorial-standards.md` §6 和 `AGENTS.md` 中的抖音条目，并替换旧的"3—5条引流短稿"模式。事实与证据边界仍以 `docs/project-spec.md` §4—§5 和各题材 `07-risk-review.md` 为准；本规约不降低任何事实标准。长视频生产规约见 `docs/narrative-production-standard.md`，两者并行适用。

## 一、定位

- 抖音主站是**独立内容阵地**，不是长视频的引流附庸；不再制作随机截取或纯预告性质的引流短稿。
- 同一题材保持两种成片形态：B站/YouTube/抖音精选 长视频（20—40分钟，共用平台中性母稿）与抖音主站独立成片（5—8分钟，一集讲完）。
- 抖音精选是长视频分发渠道，沿用长视频母稿体系，不属于本规约范围；本规约只约束抖音主站的5—8分钟独立成片。
- 两种形态共用同一题材证据库（`C###`—`S###`）。抖音文案可以**删减**事实，不得**改写**事实。
- 目标群体：泛知识区、对商业故事感兴趣的成年观众（有无专业金融背景均可），以及具备一定知识程度的高中群体；默认观众接得住梗，但不依赖专业金融背景。校准细则见"三、文案规约"第5节。

## 二、成片形态硬规约

1. 一个故事只做**一集**，成片5—8分钟；不得拆成上下集或系列。
2. 所有叙事在本集内闭环：悬念当集兑现，不设"下集见"，不制造虚假断点。
3. 成片沿用全程旁白、不露脸呈现。
4. 文案独立创作，不得直接剪辑长视频成片充当抖音内容；允许复用母稿的类比、意象与分镜资产。
5. 数字口径与法律限定沿用题材事实矩阵；口播或字幕层必须保留"指控/和解/当时"等限定语，可精简、不可删除。
6. 画幅默认横屏16:9，优先复用长视频视觉资产；竖屏重构待数据验证后再启动。

## 三、文案规约

### 1. 开头钩子（0:00—0:30/0:45）

- 开头30—45秒内必须完成钩子，随后立即进入主线；不放片头、不自我介绍、不做背景铺垫。
- 钩子三件套：**一个具体人物或机构 + 一件反常/荒诞的事实 + 一个留在观众心里的问题**。问题由场景与反差自然生成，旁白不抛出"到底为什么"式口播提问，不自问自答。
- 第一句即进入具体信息，禁止"今天给大家讲一个……"式开场。
- 钩子从事实矩阵中选最强反差，三选一：结果前置（富县破产）、身份反转（警告者落选又接盘）、机制荒诞（为赚利差专门发债）。
- 前45秒出现的新人物名不超过2个。

### 2. 主线减法（只讲荒诞，不求完整）

- 只保留**2—4名**最相关人物；每名保留人物必须有可证实的行动改变局面，不得沦为责任标签。
- 不要求覆盖长视频的完整因果链；允许舍弃支线、次要配角与机制细节。
- 舍弃标准：删掉后主线荒诞感不变→删；删掉后观众无法判断事件分量→留。
- 机制解释全片总计不超过120秒，单段不超过40秒（比长视频"单段≤90秒"更紧）。
- 核心数字全片不超过4组；其余数字移入字幕层。
- 可以调整叙事顺序，但不得改变事实的因果关系和已知时间顺序。

### 3. 荒诞感

- 荒诞 = **可证实事实之间的落差**，不是修辞强度；每个荒诞点必须能回指 `C###`。
- 每45—90秒安排一个"新信息或新反转"节拍；连续两个节拍无人物行动即视为节奏事故。
- 不虚构对白、内心活动、私人关系或未证实动机；演绎性概括与长视频同一标准。
- 不移植任何创作者的口头禅、固定句式、人设或标志性梗。

### 4. 结尾（最后20—40秒）

- 先落人物命运，再给一句主题判断，随后停止；不叠多个升华。
- 以一个评论区问题收尾；问题必须指向片内事实，不引导对具体个人的攻击。

### 5. 受众与玩梗校准

- 类比、梗和吐槽取自生活常识与通用网络语境；不依赖金融从业背景，不使用需要解释才能懂的圈内黑话。
- 观众默认接得住梗：允许中等密度的网感表达与反差吐槽，但每个梗必须服务于理解或记忆点；连续堆梗视为节奏事故。
- 专业术语首次出现必须一句话转译，确保高中知识程度的观众不掉队（与最小参照系规约一致）。
- 避免强时效梗；成片按可长期检索的生命周期设计。

## 四、结构模板（弹性检查表，非公式）

| 段落 | 时长占比 | 任务 |
|---|---|---|
| 钩子 | 30—45s | 人物 + 反常事实 + 未答问题 |
| 建局 | 60—120s | 谁想要什么，局面为什么当时合理 |
| 节拍推进 | 2—4个节拍 | 荒诞递进，每拍新信息 + 新问题 |
| 反转/崩塌 | 60—120s | 关系反转，代价落地 |
| 收束 | 20—40s | 人物命运 + 主题一句 + 评论引导 |

节奏检查：

- 沿用口播门禁：每20—30秒应出现人物动作、局面变化、具体例子或新问题之一。
- 时间跳跃必须有年份、日期或"此前/随后"等坐标。

## 五、参照策略（知识区短视频共性打法）

参照 IC实验室 等知识区博主的共性策略，**只借鉴结构原则，不借鉴表达**：

- 高信息密度开场，"内容承诺"前置；
- 节拍化推进，按留存曲线管理信息释放；
- 生活化类比一次性转译陌生机制，不复用第二遍；
- 关键词字幕化、数字高亮，服务静音观看与快速滑动场景；
- 结尾互动引导服务于评论区生态。

不得移植口头禅、标志性句法、转场风格或人设元素（沿用既有硬规约）。

## 六、包装

- **标题：** 数字反差或人物冲突二选一；沿用在案法律边界（如"他赢了"仅指选举）。
- **封面：** 主文案不超过12字、副文案不超过8字（待A/B校准）；避免绝对化表述。
- **字幕：** 简体大字号，关键数字与日期卡高亮；成片字幕按事实矩阵逐句复核。
- **置顶评论：** 补充上下文、来源口径或勘误，不替代正片信息。
- 话题标签与发布时间：运营参数，留待数据复盘确定。

## 七、合规与风险

- 不构成任何投资建议；不出现收益承诺、荐股暗示或"稳赚"类表述。
- "被指控/被起诉/被判决/和解/承认"动词边界、人物名誉表述沿用题材 `07-risk-review.md`。
- 发布前对照平台财经内容规则做敏感词自查，口播与字幕同步检查。
- 替代画面的"示意"标注规则适用于抖音成片。

## 八、生产流程（题材内）

1. 长视频母稿与事实矩阵完成后（或同步），从证据矩阵选取主线荒诞链与2—4名保留人物；
2. 撰写抖音文案：文案主体写入题材 `script/douyin.md`（保留 `C###` 标注的工作稿）；标题、封面、简介、置顶评论写入 `script/platform-packages.md` 新增"抖音主站"节；
3. 人工核对 `C###` 引用绑定（编号体系保留在架构稿与事实矩阵，成片文案正文不出现编号；`scripts/audit_claims.py` 检查研究层闭合，抖音稿引用暂靠人工）；`audit_voiceover.py` 可用于句长与报告腔预警；
4. 实测朗读计时，确认5—8分钟区间；
5. 完成包装、合规自查与发布登记；复盘写入 `08-publish-review.md` 抖音栏。

## 九、数据复盘口径

- 核心指标：前3秒/前30秒留存、平均观看时长、完播率、互动率（赞评转）、关注转化。
- 5—8分钟在抖音属中长区间，完播率基准与纯短视频不同；先积累自有基线，再设阈值。
- 每期复盘必须记录：钩子段流失假设、各节拍留存、评论高频质疑（回填题材风险审查）。

## 十、门禁清单

- [ ] 一集讲完，5—8分钟，无多集拆分
- [ ] 钩子在30—45秒内完成，含三件套
- [ ] 保留人物不超过4名，且各有可证实行动
- [ ] 机制解释总量不超过120秒，单段不超过40秒
- [ ] 核心数字不超过4组
- [ ] 所有事实可回指 `C###`，删减不改写
- [ ] 无虚构对白/动机，无移植他人表达
- [ ] 法律限定语在口播或字幕层保留
- [ ] 结尾当集闭环 + 单一评论引导
- [ ] 复盘指标与评论质疑回填完成
