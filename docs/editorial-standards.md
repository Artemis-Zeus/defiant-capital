# 编辑与选题规范

## 1. 栏目使命

用轻松、清晰、可核验的方式讲述离谱资本故事：先让观众愿意听下去，再让观众理解事件背后的资本、商业、人性或制度机制。

统一风格：**悬念故事为骨架，资本机制为内核，克制的黑色幽默作为调味。**

## 2. 题材优先级

1. 骗局与金融犯罪：核心主线。
2. 商业豪赌与作死：核心主线。
3. 资本史与制度荒诞：特色支线。
4. 逆天改命与财富跃迁：精选支线，只收录非常规、强反差或具争议机制的案例。

## 3. 地域与风险边界

- 海外案例优先。
- 国内仍在经营的企业，原则上不作为负面主角。
- 国内正向案例可以收录，但须小众、反差强、资料可靠。
- 负面题材优先采用已有法院裁判、监管结论、破产清算或充分历史定论的案例。
- 公开仓库中的未核验材料必须显著标注状态，不得写成项目结论。
- 对仍可能造成现实伤害的指控，写明“谁在何处提出了什么说法”，不得把指控改写为事实。

## 4. 正式选题门槛

正式选题原则上同时满足：

- 有可靠或权威信源；
- 有清晰冲突、升级和反转；
- 能解释一种资本、商业、人性或制度机制；
- 具备新颖度与可讲述性。

影像资料是软门槛。缺少直接影像时，可以规划合规的情境替代画面。

## 5. 叙事原则

- 开头尽快给出人物反差、离谱结果或核心谜团，不先讲百科背景。
- 按“承诺或野心 → 第一次成功 → 风险升级 → 关键反转 → 失控与结局 → 机制解释”组织主体。
- 吐槽服务于理解和节奏，不替代证据，不贬损无关群体。
- 机制分析紧跟具体剧情，避免独立成一堂抽象财经课。
- 结尾回答：这件事为什么会发生、谁付出了代价、今天还能看到什么相似机制。
- 不照搬任何创作者的固定口头禅、段子或具体表达。

## 6. 平台策略

- B 站与 YouTube 共用平台中性的长视频母稿。
- B 站包装强调社区语境、故事密度、人物荒诞感和适量梗文化。
- YouTube 包装补足英文原名、地区、年代及制度背景；章节与屏幕文字适合电视端观看。
- 抖音不随机截长稿，独立制作 3–5 条可单独理解、但保留一个重要悬念缺口的短稿。
- 长视频默认规划为 20–40 分钟；故事需要时可自然延长并分章。
- 成片采用全程旁白、不露脸的呈现方式。
- YouTube 首期仅制作简体中文字幕。
