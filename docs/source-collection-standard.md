# 史料收集规约 V1.0

本规约规定"线索 → 研究建档"阶段史料的收集范围、检索渠道、覆盖要求、验证操作与标注方式，沉淀橙县题材研究的可复用做法。它回答四个问题：收什么、去哪收、怎么验、怎么标。

## 与既有文档的分工

| 文档 | 职责 |
|---|---|
| 本规约 | 收集范围、渠道、覆盖度与验证操作 |
| `docs/research-and-sources.md` | 来源等级（A—D）、来源记录字段、事实状态、保存与版权边界 |
| `docs/narrative-production-standard.md` §三 | 每名人物的叙事数据字段与四种观众参照 |
| `skills/research-capital-story/SKILL.md` | 研究建档流程骨架与退出门禁 |
| 题材 `03-sources.md` / `04-claims.md` | 来源卡与主张—证据矩阵的实际载体 |

事实标准不因本规约降低；`docs/project-spec.md` §4—§5 仍然优先。

## 一、史料分类清单（收什么）

| # | 类别 | 典型材料 | 能证明 | 不能单独证明 |
|---|---|---|---|---|
| 1 | 司法与监管文书 | 判决书、SEC行政命令与执法稿、监管调查报告、州审计报告、GAO报告 | 破产、处罚、禁令、损失定论、程序边界 | 动机；调查报告不等于个别事实裁判 |
| 2 | 政府与立法记录 | 国会听证与当事人书面陈述、预算文件、政府公报、总统档案馆材料 | 政策口径、当事人自述履历、公共开支结构 | 陈述内容的真实性；预算总数≠可自由挪用 |
| 3 | 法定披露与财务文件 | 年报、投资报告、财务报表、募集说明书 | 规模、收益率、发行与融资结构 | 内部决策过程 |
| 4 | 同期新闻报道 | 事发窗口内的报纸、杂志、通讯社报道 | 时间点、当时公开信息、当时舆论 | 数字的精确口径；相互转载不算独立 |
| 5 | 当事人公开陈述与事后叙述 | 证词、访谈、自传、纪录片 | 履历自述、立场与解释 | 任何"其声称"之外的事实 |
| 6 | 学术与专著研究 | 联储地区研究、政策研究机构报告、学术论文、严肃传记 | 背景机制、地区经济、制度约束 | 事件细节的一手证明 |
| 7 | 数据序列 | 利率、GDP、就业、价格与行业数据（联储、NBER、BLS等） | 宏观与地区背景、幅度与时间 | 微观归因 |
| 8 | 视觉与影像素材 | 同期照片、新闻画面、文书扫描件 | 画面线索 | 仅登记链接与版权状态，不入仓库 |

收集要求：

- 每个正式题材的第1—4类是主干；缺任一类时，题材 README 必须写明"不适用"或"缺口"。
- 第5类必须与第1—4类分层使用；第6—7类承担背景与参照系。
- 中文圈二手内容（百科、自媒体、聚合站）只作线索入口，不进定稿。

## 二、检索渠道与收集方法（怎么收集）

### 渠道表（按类别，入口以橙县题材验证过的为准）

1. **司法与监管**：SEC 执法与行政程序页面、州审计局报告库、GAO 报告库。
2. **政府与立法**：国会听证与当事人书面陈述的历史档案（如 sechistorical.org）、县政府公报与预算文件、总统图书馆档案馆（如 reaganlibrary.gov）。
3. **法定披露**：EDGAR、市政发行披露汇编、财税官办公室财务与投资报告。
4. **同期报道**：主流报纸历史档案（如 latimes.com/archives），按事件日期窗口检索。
5. **当事人陈述**：国会听证数据库、可定位的访谈与纪录片。
6. **学术与专著**：联储地区研究（如 FRBSF Weekly Letter）、政策研究机构（如 PPIC、加州 LAO）、NBER、Google Scholar。
7. **数据序列**：federalreserve.gov 历史利率表、federalreservehistory.org、NBER 周期测定公告、官方统计库。
8. **视觉素材**：档案馆与媒体授权页，只登记链接、用途与版权状态。

### 收集方法

1. 先建人物/机构表，再沿时间线收集；每名核心人物按叙事六字段列出"证据需求点"，按点定向收集，不做无目标漫游。
2. 每个证据需求点先问"什么材料能直接证明"，优先攻第一类能直接证明的来源；一类拿不下来再降级为多源交叉组合。
3. **收集即建卡**：找到材料即建 S### 卡并完成摘录与定位，不允许"先囤链接、后补卡片"。
4. 同期报道检索先定日期窗口（事件前后各数日），确认首发来源后再扩展转载链。
5. 注意版本：修订稿、勘误、再版与口径差异并存时，记录所引版本及差异点。
6. 链接失效对策：优先记录官方镜像与合法公开档案；原始链接与访问日期必须保留。
7. 付费墙材料：只记录可公开验证的元数据与已获授权的最小摘录；不绕过付费墙。
8. AI 摘要与搜索摘要只作导航，不得作为来源卡内容或事实依据。

## 三、角色与时间线覆盖要求

### 人物覆盖

| 角色 | 最小证据集 |
|---|---|
| 绝对主角 | 叙事六字段各有证据；"当时所知"必须有决策前材料；至少一条警告或替代方案的证据 |
| 核心配角 | 可证实行动 + 该行动如何改变主角处境的证据 |
| 机构型角色 | 激励结构 + 允许或不阻止事件发生的行为证据；不强行个人化 |
| 代价承受者 | 谁被波及 + 至少一条体量或后果证据 |

### 时间线覆盖

- 双轨标注：每个节点区分"事件发生时间"与"证据时间属性"（当时记录 / 事后叙述 / 事后研究）。
- 每个关键决策点必须至少有一条"当时"材料支持"决策前已知道什么"。
- `02-timeline.md` 每行必须回指 `C###`—`S###`；无来源行不得作为主线依赖。
- 相邻关键节点间隔超过约5年时，检查是否遗漏节点。

## 四、验证操作规程（怎么验）

1. **独立性判定**：两篇材料若同源（相互转载、同一通讯社、同一匿名源、同一发布网络），只算一条。来源卡"独立性"字段必须标明原创 / 转述（S###） / 未知。
2. **当事人口径**：当事人陈述只写"声称/表示"，与监管认定、司法结论分层，不得混用。
3. **数字复核**：单位、币种、名义/实际、时点、口径、约数来源逐项核对；跨来源冲突登记到 `04-claims.md` 口径表，不得默默取一。
4. **引语复核**：直接引语逐字回原文；翻译忠实为先，不放大语气。
5. **时间与因果**：因果链不得早于其证据的时间属性；时间先后不等于因果。
6. **反驳证据搜索**：每个关键主张至少执行一次主动反例检索（否定词组合、当事人否认、后续勘误、学术修正），结果记入来源卡"反驳的主张"。
7. **状态维护**：证据变化时同步升降 `04-claims.md` 状态；"已交叉验证"的独立性条件消失时必须降级。
8. **缺口处理**："没有找到证据"不等于"证伪"；缺口如实保留并登记。

## 五、标注与归档（怎么标）

- 来源卡按 `topics/_template/03-sources.md` 字段执行，字段齐备才算"已收集"；暂缺字段标注"待补"。
- 主张按 `topics/_template/04-claims.md` 执行；每条主张同时列支持来源与反驳来源。
- 访问日期按批次记录；重大补录批次单独标注。
- 母稿引用 `[C###]` 的规则见 `docs/narrative-production-standard.md` §五。
- 版权与保存边界按 `docs/research-and-sources.md` §6 执行；本规约不新增任何完整保存授权。
