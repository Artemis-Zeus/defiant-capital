# 研究与信源规范

## 1. 基本证据门槛

关键事实优先使用一手材料或权威来源。缺少一手或权威来源时，至少由两家相互独立的可靠来源交叉验证。

两篇互相转载、共同依赖同一匿名消息，或同属一个未经独立采编的内容网络的报道，不算交叉验证。

## 2. 来源等级

| 等级 | 典型来源 | 用法 |
|---|---|---|
| A | 法院文书、监管文件、公司正式披露、政府档案、原始合同或数据、同期原始影音 | 优先支持关键事实 |
| B | 有署名、有编辑标准、能说明消息来源的严肃媒体或专业研究 | 可支持一般事实；高风险事实尽量交叉验证 |
| C | 当事人回忆、采访、自传、纪录片、行业媒体、学术二手研究 | 支持视角与背景，注意立场和时间差 |
| D | 聚合站、自媒体、论坛、社交媒体、百科 | 仅作线索入口，原则上不能单独进入定稿 |

等级评估的是当前材料对某项事实的证明力，不是对机构的永久评级。

## 3. 来源记录字段

每条来源分配唯一编号，如 `S001`，并至少记录：

- 标题；
- 作者或发布机构；
- 发布日期；
- 原始链接；
- 访问日期；
- 来源等级；
- 来源类型；
- 原文摘录；
- 中文翻译；
- 页码、段落、章节或时间戳；
- 它支持或反驳的事实编号；
- 利益关系、偏见或局限；
- 第三方材料的版权、许可或公有领域状态及判断依据；
- 链接失效时的替代入口或合法归档状态。

外文翻译以准确为先；有歧义的术语保留原文，不把推断塞进译文。

## 4. 事实状态

只允许使用以下五种状态：

- `线索`：尚未查证，只用于引导研究。
- `待核验`：已有材料，但尚未达到定稿门槛。
- `已交叉验证`：两家相互独立的可靠来源互相印证。
- `权威定论`：有一手、司法、监管或同等强度材料明确支持。
- `存在争议`：可靠来源之间存在实质冲突，或相关方明确否认且证据不足以消除争议。

## 5. 事实—证据绑定

- 每项可争议的关键事实分配编号，如 `C001`。
- 每项事实必须列出支持来源、反对来源与当前判断。
- 母稿中的关键事实使用内部引用标记，如 `[C001]`；发布前可转换为口播归因、简介链接或字幕注释。
- 数字、引语、首次/最大/唯一等绝对表述，以及人物动机，必须重点复核。
- “没有找到证据”不等于“证伪”；“有人声称”不等于“事情发生”。

## 6. 网页与材料保存

### 6.1 可以完整保存的材料

仅在第三方材料明确属于公有领域，或权利人、许可条款明确允许完整保存并公开分发时，才可在仓库中保存完整网页、报告、PDF、截图或快照。来源卡必须记录授权依据与适用范围。

### 6.2 其他第三方材料

对于未获明确授权、版权状态不明或许可不允许公开归档的材料：

- 仅保存原始链接、完整引用信息、访问日期、为核验所必需的最小摘录和精确定位；
- 不上传整篇网页、整份报告、完整 PDF 或用于替代原作的连续大段内容；
- 摘录应与证明或反驳具体事实直接相关，不得超出研究、评论和核验所需范围；
- 如需降低链接失效风险，记录官方镜像、合法公开档案或互联网档案链接，不自行复制未获授权的完整内容。

版权状态不明按“未获完整保存授权”处理。仓库中的链接、引用和必要摘录不代表第三方内容获得再许可。
