# 逆天的资本（Defiant Capital）

面向 B 站为主、YouTube 为辅、抖音负责引流的“离谱资本故事”知识库。

本仓库覆盖从线索收集、事实考证、选题策划、长视频文案，到发布复盘的完整内容生产流程。核心题材包括：

1. 骗局与金融犯罪
2. 商业豪赌与作死
3. 资本史与制度荒诞
4. 逆天改命与财富跃迁

## 内容定位

叙事原则是：**悬念故事为骨架，资本机制为内核，克制的黑色幽默作为调味。**

选题以海外案例为主。国内仍在经营的企业原则上不作为负面主角；国内正向案例可以收录，但应小众、有反差、有可靠资料，避免普通励志或大众熟知题材。

## 事实与信源原则

- 关键事实优先使用一手材料或权威来源。
- 缺少一手或权威来源时，至少由两家相互独立的可靠来源交叉验证。
- 明确区分：线索、待核验、已交叉验证、权威定论、存在争议。
- 外文信源保留原文摘录、中文翻译和页码、段落、章节或时间戳等精确定位。
- 每项关键事实应能反向定位到对应证据。
- 仅完整保存授权明确允许公开归档或属于公有领域的第三方材料；其他材料只保存链接、必要摘录和精确定位。
- 调查过程允许公开，但不得把未经核验的材料写成项目结论。
- 负面题材优先选择已有判决、监管处罚、破产清算或历史定论的案例。

## 选题准入

正式选题原则上同时满足：

- 存在可靠或权威信源；
- 有清晰的冲突、升级与反转；
- 能解释一种资本、商业、人性或制度机制；
- 具备可讲述性与新颖度。

影像资料是软门槛。仓库只记录素材链接、内容说明和版权状态，不保存媒体文件；缺少直接影像时，可规划合规的情境替代素材。

## 内容生产

- 每个正式题材使用一个独立完整目录。
- B 站与 YouTube 共用一份平台中性的长视频母稿。
- 两个平台分别维护标题、封面/缩略图、简介、章节、字幕和平台口播等包装内容。
- 抖音独立制作 3–5 条可单独理解、带有悬念缺口的引流短稿。
- 长视频默认规划为 20–40 分钟；故事需要时可自然延长并分章。
- 成片采用全程旁白、不露脸的呈现方式。
- YouTube 首期仅制作简体中文字幕。
